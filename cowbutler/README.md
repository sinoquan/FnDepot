# 牛管家 · CowButler

> 飞牛 fnOS 上的系统管家：打开即用，不登录、不采集、数据不出本机。

牛管家（CowButler）把 NAS 日常要盯的事收拢到一个面板里：体检、清理、硬盘健康、安全巡检、
流量统计、Docker 与应用治理。它不替换 fnOS 的任何功能，只是把散落各处的信息汇总起来，
**在出问题之前提醒你**。

![牛管家](https://raw.githubusercontent.com/sinoquan/FnDepot/main/cowbutler/icons/icon.png)

## 它能做什么

| 能力 | 说明 |
|---|---|
| 一键体检 | 十几项检查汇总成一个评分，按「危险 / 警告 / 建议」分级，每条都给处理办法 |
| 系统清理 | 日志、缓存、临时文件、应用残留、空目录、重复文件、大文件；默认只勾安全项，删前逐条确认 |
| 硬盘与存储 | SMART 关键指标与完整属性表、坏道扫描与测速、存储空间按卷展示组盘方式与成员盘（品牌·型号·序列号） |
| 网络安全 | 外部连接、登录失败、封禁记录、防火墙与 SSH 加固建议 |
| 流量统计 | 按容器 / 进程 / 服务 / 地区 / 运营商 / 协议 / 网卡七个维度拆分，数据全部在本地 |
| Docker | 容器、Compose、镜像、网络、日志，以及加速源与代理诊断 |
| 应用与自启 | 应用商店镜像与更新检查、开机自启服务管理（关掉会缩短开机时间） |
| 通知 | 微信（企业微信 / Server 酱）、邮件、Webhook，支持静默时段与每日简报 |

## 安装

**方式一：手动安装（最稳）**

1. 按设备架构下载本目录 `fpk/` 下的安装包：`cowbutler-<版本>-x86_64.fpk`（Intel / AMD）或
   `cowbutler-<版本>-arm64.fpk`（ARM，如 RK3588 / N100 的 ARM 机型）；
2. 打开 fnOS「应用中心 → 手动安装」，选择该文件；
3. 安装完成后在应用中心启动，左侧应用列表会出现「牛管家」。

**方式二：通过 Moo 应用中心（社区商店）**

1. 在 Moo 的搜索框里直接粘贴 `https://github.com/sinoquan/FnDepot`，会自动识别为应用源；
2. 搜「牛管家」→ 安装，Moo 会按本机架构自动选对包并校验 sha256。

**方式三：飞牛第三方源**

「应用中心 → 第三方源」添加 `https://raw.githubusercontent.com/sinoquan/FnDepot/main/fnpack.json`。

> 本应用需要读取系统底层接口（SMART、连接跟踪表、Docker），安装类型是 **root**。
> 这不影响你日常使用——服务由应用中心以 root 拉起，你用什么账号登录面板都可以。
> 也因为这一点，飞牛官方应用商店暂不收录，请走上面三个渠道。

## 更新

- 软件**每天晚上 20:00–24:00 之间随机**检查一次更新（一天只查一次，避免打扰）；
- 左下角版本号旁出现「更新」徽标，点一下就能看到这次更新了什么；
- 也可以随时在「关于产品 → 检查更新」手动检查；
- 更新包会做 sha256 校验，校验不通过会中止安装。

更新信息统一放在本目录的 [`update.json`](update.json)，安装包放在 `fpk/`。

本目录同时已登记进仓库根目录的 `fnpack.json`（飞牛第三方源）与 `moo.json`（Moo 应用源）。

## 版本记录

### 1.0.12

- **修复代理测试误判**：Docker 设置页「HTTP 代理」一行的测试，原先会把非代理端口误判成「通过」；
  现在改用 CONNECT 隧道 + registry 特征校验（`Docker-Distribution-Api-Version` 头 / 401 + Docker 认证域），
  只有真的连到了 Docker 仓库才算通；
- **统一「可更新」计数口径**：右上角徽标、概览文案、容器列表筛选三处数字现在完全一致——
  只统计现存容器、排除已删除容器的残留记录、包含镜像过期的容器；
- **检查更新时清理残留**：已删除的容器不再留下可更新记录。

### 1.0.11

- **Docker 代理测试**：设置页 HTTP / HTTPS 代理后新增「测试」按钮，点一下显示延迟多少毫秒，
  失败会用人话说明原因（连接超时、代理被拒绝、目标不像 Docker 仓库等）；
- **更新检测每 8 小时一次**：Docker 容器更新检测从每天一次改为每 8 小时一次（H / H+8 / H+16）；
- **静默刷新 + 显眼的检查更新按钮**：Docker 页右上角刷新改为 15 秒静默刷新，不再需要手动点；
  「检查更新」做成显眼的小图标按钮，带可更新数量徽标；
- **通知清理**：通知中心新增「通知清理」，可勾选严重 / 警告 / 提示 / 未读 / 全部，一键清理所选记录。

### 1.0.10

- **测速按钮不再有任何动画**：运行态图标改为停止方块（此前的旋转圆弧左右不对称，被反馈「白色旋转不对称不匹配」）；
- **磁盘信息表头「设备」改为「类型」**：直接显示 SSD / HDD，设备名（sda / nvme0n1）与序列号移到悬浮提示里；
- **一键体检的问题模块可直接点击跳转到对应页面**：硬盘与存储 → 硬盘页、系统运行 → 硬件页、
  安全防护 → 安全页、数据安全 → 文件页、应用服务 → 应用页；全部通过的模块点击仍是筛选该类问题；
- **修复白屏**：「前往」按钮原会跳到不存在的页面，导致主区域一片空白；现在备份类问题落到文件页，
  任何不存在的页面 id 都会回首页，且不会把无效地址留在地址栏；
- **测速不再被「请先选择测速节点」拦截**：节点列表没加载完时直接按「自动选择（国内最优）」开始。

### 1.0.8

- **修复「带宽测速」点击开始后按钮一直闪、测速不动**：状态轮询遇到一次网络抖动就会永久停表，
  界面却停在「测速中」，按钮上的红色光环一直呼吸、表盘和曲线冻住，刷新页面才能恢复。
  现在单次失败不再中断（连续 3 秒拿不到状态才回退），卡住后点一下按钮即可自愈；
- **按钮空闲时不再有装饰性呼吸光环**：静止 = 可以点，红色呼吸 = 正在测速；
- 修复「磁盘测速」历史记录一直空白（方法名被外网测速覆盖）；
- 1.0.7 的安装兼容性修复继续生效（官方 `fnpack` 封装、最低系统版本 0.8.0）。

### 1.0.7

- **修复部分设备安装时报「不是有效的 fpk 文件」**：改用飞牛官方 `fnpack` 重新封装，
  并把最低系统版本要求从 1.2.1102 下调到 0.8.0（之前那个值等于开发机自己的系统版本，
  比它旧的系统一律装不上）；
- 磁盘信息新增**读取 / 写入实时速率**（每 2 秒刷新，休眠盘显示「休眠中」）；
- 磁盘信息新增**接口**列（SATA / NVMe），型号显示品牌（如 七彩虹 Qichen A500）；
- 修正首页「存储空间」总容量虚高（原先把容器挂载与系统盘一并计入，21.5TB → 实际 10.7TB）；
- 休眠硬盘不再显示「无法读取」，状态列直接显示「休眠」，且查询本身**不会唤醒**休眠盘；
- 硬盘风险提示按「盘 + 问题类型 + 序列号」记忆，点过「知道了」后同一问题不再重复提醒；
- 硬件概览只显示已插的内存条，空插槽不再铺满一屏（虚拟机里尤其明显）；
- 应用市场标注数据来源为 **fnOS Apps**，该条目置顶并加星标。
